Steps to Perform: 2D Shapes Using JFrame

1. Open NetBeans and create a new Java Application.
2. Right-click the project → New → JFrame Form.
3. Enter Class Name `NewJFrame` and Package Name `pkg2dshapeframe`.
4. Drag and drop a JPanel onto JFrame.
5. Drag and drop three JButtons onto JPanel.
6. Change button text to Rectangle, Ellipse and Line using Edit Text.
7. Open the Source tab and import the required packages:
   ```
   import java.awt.*;
   import java.awt.geom.*;
   ```
8. Right-click Rectangle → Events → Action → actionPerformed.
9. Write the Rectangle drawing code inside its event method.
10. Repeat the same process for Ellipse and Line buttons.
11. Save the program using `Ctrl + S`.
12. Right-click `NewJFrame.java` → Run File.
13. Click each button to display the respective 2D shape.

Result: Successfully demonstrated Rectangle, Ellipse and Line shapes using Java Swing JFrame.
